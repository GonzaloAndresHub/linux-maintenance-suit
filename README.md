# linux-maintenance-suite

> One-command Linux cleaner for IT support: removes broken packages, old kernels, cache and more.

## What it does

| # | Task |
|---|------|
| 1 | Updates package lists |
| 2 | Fixes broken/inconsistent packages |
| 3 | Removes orphaned packages |
| 4 | Clears APT cache |
| 5 | Detects duplicate/outdated PPAs |
| 6 | Removes old kernels |
| 7 | Clears user cache & thumbnails |
| 8 | Compresses and rotates system logs |
| 9 | Cleans temp files |
| 10 | Frees RAM (page cache, dentries, inodes) |
| 11 | Removes old Snap revisions |
| 12 | Shows final disk & RAM summary |

## Usage

Paste this directly into your terminal — no file needed:
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/GonzaloAndresHub/linux-maintenance-suit/main/linux_clean.sh)
```
